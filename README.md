# みちしるべ

トレーニングを長く続けるための目標アプリ。
目標 → 週に何回 → 今日の1手 の3段で、遅れたら気力ではなく目標のほうを調整する。

スマホのホーム画面に追加して使う（PWA）。記録は端末のブラウザ内に保存され、外部には送らない。

## 画面

- **今日** — 今日の1手に印をつける。直近14日の記録をその場で直せる
- **目標** — 経過日数に対する進み具合（軌道）と到達予測。遅れていれば期限延長や目標の下方修正を提案する
- **ふりかえり** — 週に1度、3問だけ。来週の1手を書き替えるとそのまま反映される

## 作りなおし方

このフォルダは `michishirube/index.html` から生成している。アプリ本体を直したら

```
cd ../michishirube
node build-pwa.js
```

で index.html・manifest・sw.js・アイコンが再生成される。
